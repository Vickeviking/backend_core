# Web App

This app is the initial React + TypeScript + Vite frontend shell for the refactor.

## Commands

- `npm run dev`
- `npm run build`
- `npm run lint`

## Backend Integration

The frontend reads the backend base URL from `VITE_API_BASE_URL`.

Default:

`http://127.0.0.1:8000`

## Current Scope

The app currently provides:

- a shared layout and navigation shell
- placeholder pages for future product work
- a backend health-check page
- a small API client module for backend access

It does not yet implement the full auth or newsletter UI.
